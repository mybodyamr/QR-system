# فارز البلتات

تطبيق PWA بسيط لمخازن الاستلام: امسح باركود الكرتونة، ياخد رقم بلتة جديد أول مرة، ويفتكره في المرات اللي بعد كده.

## رفعه على GitHub Pages (خطوات سريعة)

1. اعمل ريبو جديد على GitHub (مثلاً `pallet-sorter`).
2. ارفع كل الملفات اللي في المجلد ده زي ما هي (بنفس الأسماء والمسارات):
   ```
   index.html
   manifest.json
   sw.js
   icons/  (المجلد بالكامل بكل الصور اللي جواه)
   ```
3. من إعدادات الريبو: `Settings → Pages → Source` اختار الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اتنين، هيديك رابط شبه:
   `https://<اسمك>.github.io/pallet-sorter/`
5. افتح الرابط من موبايل الأندرويد أو الآيفون، وهيظهرلك خيار "إضافة إلى الشاشة الرئيسية" / "Add to Home Screen" — بعدها هيفتح كتطبيق مستقل بأيقونته من غير شريط المتصفح.

## مهم قبل ما تعتمد عليه في الشغل الفعلي

- **البيانات محفوظة محلياً على كل جهاز لوحده** (`localStorage`) إلا لو فعّلت المزامنة السحابية (اقرأ تحت).
- الكاميرا للمسح محتاجة HTTPS عشان تشتغل — وGitHub Pages بيديك HTTPS تلقائي، فمفيش مشكلة هنا.

## تفعيل المزامنة الحقيقية بين كل الموبايلات (اختياري)

التطبيق فيه دلوقتي زرار ⚙️ فوق بيسمحلك تربطه بمشروع Firebase مجاني، فيبقى كل الموبايلات شايفة نفس البيانات لحظياً. الخطوات:

1. روح على https://console.firebase.google.com وسجل دخول بحساب جوجل عادي.
2. دوس "Add project" واعمل مشروع جديد باسم أي حاجة (مثلاً `pallet-sorter`). مش لازم تفعّل Google Analytics.
3. من قايمة المشروع، دوس على أيقونة **Web (</>) ** عشان تضيف تطبيق ويب، وهيديك كائن كود شكله كده:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
   انسخ الكود ده كله.
4. من القايمة الجانبية: **Build → Firestore Database → Create database**. اختار "Start in test mode" عشان تبدأ بسرعة (مناسب لأداة داخلية صغيرة زي دي).
5. افتح التطبيق على أي موبايل، دوس ⚙️ فوق، الصق الكود اللي نسخته في خانة "بيانات مشروع Firebase"، واكتب أي كود بسيط في خانة "كود الفريق" (مثلاً `mahzan1`) — **نفس الكود بالظبط** لازم يتكتب في كل موبايل عايز يشوف نفس البيانات.
6. دوس "حفظ واتصال". لو ظبط، هتلاقي النقطة جنب اسم الحاوية بقت خضرا ومكتوب "متزامن".
7. كرر الخطوة 5 و6 بس على باقي الموبايلات (بنفس بيانات الكود وكود الفريق).

**ملحوظة أمان:** "Test mode" في Firestore بيخلي أي حد معاه رابط المشروع يقدر يقرا/يعدل البيانات لمدة 30 يوم بس، بعدها بيتقفل تلقائي. لأداة داخلية صغيرة للمخزن الأمر ده غالباً مقبول، لكن لو عايز تأمين أقوى أو استخدام دائم، محتاج تظبط "Firestore Security Rules" بعدين — قولّي لو حبيت مساعدة في الخطوة دي.


## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق نفسه |
| `manifest.json` | بيانات الـ PWA (الاسم، الأيقونة، الألوان) |
| `sw.js` | service worker بيخلي التطبيق يشتغل حتى من غير نت بعد أول فتح |
| `icons/` | أيقونات التطبيق بمقاسات مختلفة |
