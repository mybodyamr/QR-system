# فارز البلتات

تطبيق PWA بسيط لمخازن الاستلام: امسح باركود الكرتونة، ياخد رقم بلتة جديد أول مرة، ويفتكره في المرات اللي بعد كده.

## رفعه على GitHub Pages (خطوات سريعة)

1. اعمل ريبو جديد على GitHub (مثلاً `pallet-sorter`).
2. ارفع كل الملفات اللي في المجلد ده زي ما هي (بنفس الأسماء والمسارات):
   ```
   index.html
   manifest.json
   sw.js
   icons/  (المجلد بالكامل بكل الصور اللي جواه)
   ```
3. من إعدادات الريبو: `Settings → Pages → Source` اختار الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اتنين، هيديك رابط شبه:
   `https://<اسمك>.github.io/pallet-sorter/`
5. افتح الرابط من موبايل الأندرويد أو الآيفون، وهيظهرلك خيار "إضافة إلى الشاشة الرئيسية" / "Add to Home Screen" — بعدها هيفتح كتطبيق مستقل بأيقونته من غير شريط المتصفح.

## مهم قبل ما تعتمد عليه في الشغل الفعلي

- **البيانات محفوظة محلياً على كل جهاز لوحده** (`localStorage`)، مش متزامنة بين الموبايلات. يعني لو عاملين بيستخدموا التطبيق في نفس الوقت على تليفونين مختلفين، كل واحد هيشوف أرقام بلتات مستقلة عن التاني.
- لو محتاج كل الأجهزة تشوف نفس الأرقام لحظياً (مهم جداً في شغل فعلي بأكتر من عامل)، محتاج قاعدة بيانات خلفية بسيطة (زي Firebase Firestore المجاني أو Google Sheets API) بدل الـ localStorage. ده تطوير إضافي بسيط لو حبيت نعمله.
- الكاميرا للمسح محتاجة HTTPS عشان تشتغل — وGitHub Pages بيديك HTTPS تلقائي، فمفيش مشكلة هنا.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق نفسه |
| `manifest.json` | بيانات الـ PWA (الاسم، الأيقونة، الألوان) |
| `sw.js` | service worker بيخلي التطبيق يشتغل حتى من غير نت بعد أول فتح |
| `icons/` | أيقونات التطبيق بمقاسات مختلفة |
